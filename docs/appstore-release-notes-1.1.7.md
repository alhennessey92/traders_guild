# App Store "What's New" — Traders Guild 1.1.7 (iOS)

App Store Connect allows 4000 characters, but only the first two or three lines show before
"more", so the opening line carries the release. Voice matches the 1.1.6 notes: benefit first,
plain language, no version numbers or internal terms.

Deliberately not mentioned: the WebSocket token-logging fix. Fixed security issues don't belong in
public release notes.

---

Finding, joining and setting up a guild is much simpler this release.

• Join a guild with its handle or an invite code — paste either at signup or from the guild list
• Create a guild with just a name, then a short checklist walks you through the rest
• Request to join private guilds, and track the requests still waiting on an owner
• Redesigned guild cards and guild detail, so a guild looks the same wherever you find it
• More reliable guild sharing, with better link previews when you post to Discord

Also fixed: the keyboard now dismisses with a swipe in guild settings and admin screens, guild
lists no longer flicker while they load, and switching guild no longer briefly shows the previous
guild's members.
