# App Store "What's New" - Traders Guild 1.1.8 (iOS)

Four more crypto markets are now available in Traders Guild: BNB, Cardano, Chainlink and Sui.

* Add any of the new markets to your watchlist and move between their live and historical charts.
* Chart panning and zooming feel smoother and more responsive.
* Marker confidence is now shown as a clear 1-5 rating.
* Line indicators now support adjustable widths.
* Marker setup explains any missing requirements before you submit, with more useful price precision.

## Internal release details

* Marketing version: `1.1.8`
* Build: `18`
* No backend response fields or existing deep-link contracts change in this release.
* Older app versions can discover the new markets and use their existing generated icon fallback.
